# Doof Rush

<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/319fcdb6-9e57-42cc-acb0-69bf562c1a80" />

This is goofy platformer game featuring Daven as the main character. Very similar to the Google Chrome Dino game and Flappy Bird, but this features goofy sound effects and a hidden space mode to try. When we hit a spring , it takes the player to outer space and after we hit the springs thrice, A portal appears and we use our arrow keys to navigate into them and it takes us back to Earth. Also, as an easter egg, when you hit score “92,000”, (really hard to hit, I know) it plays “Never gonna give you up” by Rick Astley as a joke.
